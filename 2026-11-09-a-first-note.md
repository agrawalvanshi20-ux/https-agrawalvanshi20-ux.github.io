This is a placeholder so the notebook has something in it. Delete it and write your own.

A lab notebook that lives on a website is a different thing from the one on the bench.
The bench one is a record. This one is for the part that usually goes unwritten: why an
assay behaved oddly, which reagent lot turned out to matter, the small fix that saved an
afternoon. The things you only learn by running the thing yourself, and that nobody
writes into a protocol.

## How to add a note

Make a new file in the `_posts` folder, named `YYYY-MM-DD-some-title.md`, and start it
with this block:

```
---
layout: post
title: "Your title"
summary: "One line that shows on the list page."
---
```

Then write below it in Markdown. It appears on the notebook page as soon as it is
committed.
